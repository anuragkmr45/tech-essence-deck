# Tech Essence Deck

Anurag Kumar's portfolio, built with Next.js 16 App Router, React 19, TypeScript, Tailwind CSS, and shadcn/ui.

Live site: [tech-essence-deck.vercel.app](https://tech-essence-deck.vercel.app)

## Local development

Requires Node.js 20.9 or newer and npm.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

## Commands

- `npm run dev` starts the development server.
- `npm run build` creates the production build.
- `npm start` serves the production build.
- `npm run lint` runs ESLint.
- `npm run typecheck` runs TypeScript without emitting files.
- `npm run test:e2e` checks the primary navigation and interactive behaviors against a running production server. Set `BASE_URL` to the server origin.
- `npm run visual:capture` captures the route/viewport visual matrix. Set `BASE_URL` and `OUTPUT_DIR` to override its defaults.
- `npm run visual:capture-interactions` captures the key interactive visual states against a running server.
- `npm run visual:compare` compares a candidate capture with the baseline. Set `BASELINE_DIR`, `CANDIDATE_DIR`, and optionally `MAX_DIFF_RATIO`.

For browser checks against a Vercel-authenticated preview, set `VERCEL_BYPASS_COOKIE_FILE` to a Netscape-format cookie jar containing the short-lived `_vercel_jwt` cookie generated through Vercel's protection-bypass flow.

See [`docs/migration-verification.md`](docs/migration-verification.md) for the recorded migration results.

## Content architecture

The current portfolio content is static and stored under `src/data`. App Router pages read it through the async server-only repository in `src/lib/content/repository.ts`. This boundary allows a future Supabase implementation without changing the page or UI component contracts.

The project does not install or configure Supabase yet. When dynamic content is required, implement the existing `ContentRepository` interface with server-side Supabase queries and select the adapter through server-only configuration.

## SEO and deployment

Pages are statically pre-rendered with route-specific metadata and JSON-LD. `robots.txt` and `sitemap.xml` are generated by Next.js metadata routes.

Set `SITE_URL` to the canonical production origin, without a trailing slash:

```sh
SITE_URL=https://tech-essence-deck.vercel.app
```

Production Vercel builds require `SITE_URL`. Vercel preview deployments are automatically marked `noindex, nofollow` and their robots policy disallows crawling.

Deploy by importing the repository into Vercel, selecting the Next.js framework preset, and defining `SITE_URL` for the Production environment. The standard `npm run build` command is sufficient.
